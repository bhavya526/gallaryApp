# 🖼️ Gallery App

A full-stack image gallery application built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Live Demo

- **Netlify:** [https://bhavya-gallary-app.netlify.app/](https://bhavya-gallary-app.netlify.app/)
- **Vercel:** [https://memo-dgvwdahun-bhavyas-projects.vercel.app/](https://memo-dgvwdahun-bhavyas-projects.vercel.app/)

---

## 🌟 Features

- **Full-Stack Setup:** Next.js application with unified client and backend components.
- **Type Safety:** Written using TypeScript for reliable code and interface definitions.
- **Modern Styling:** Styled with Tailwind CSS and PostCSS for dynamic layouts.
- **Server Integration:** Dedicated server modules for cloud API and media handling.

---

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Linting:** ESLint
- **Hosting:** Netlify / Vercel
